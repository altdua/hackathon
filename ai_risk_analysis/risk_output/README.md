# Risk Output

Reserved for the future risk output implementation. The dashboard displays
this stage as pending until you create `agent.py` here.

Implement `run(input_path, output_dir, config, log)` and return
`{"primary_artifact": "risk_output.json"}`. The input is the selected previous
stage's primary artifact. Write all outputs inside output_dir. See the project
README for the full contract.

No risk report or placeholder scores are implemented.
